# minitalk

유닉스 시그널(`SIGUSR1`, `SIGUSR2`)을 이용해 서버/클라이언트 간에 문자열을 전송하는 간단 IPC(Inter-Process Communication) 과제입니다.

## 빌드
```bash
make
```
- `./server`, `./client` 실행 파일 생성
- `make bonus`가 있으면 보너스 버전도 생성

## 동작 개요
- 서버: 자신의 PID를 출력하고, 클라이언트로부터 비트/문자 단위로 시그널을 받아 메시지를 재구성해 출력합니다.
- 클라이언트: 서버 PID와 문자열을 입력받아, 각 비트를 시그널로 인코딩해 순차적으로 전송합니다.
- 일반적으로 신뢰성을 위해 `sigaction`(핸들러), `pause`, `kill`(시그널 전송), 전송 간 간격(`usleep`) 및 ACK 핸드셰이크를 고려합니다.

## 사용 예
```bash
./server
# PID 출력됨, 예: 12345

./client 12345 "Hello, 42!"
```

## 구현 힌트
- 비트 인코딩: `SIGUSR1` = 0, `SIGUSR2` = 1 (또는 반대로)로 약속
- 문자의 8비트를 순서대로 전송
- 서버는 비트 누적 → 바이트 완성 시 출력
- 에러/경계 처리: 잘못된 PID, 빠른 전송으로 인한 시그널 드랍, 널 종료 문자 처리 등
- 보너스에서는 양방향 ACK로 신뢰성 향상

## 의존성
